# 履歴資料

このディレクトリには、canonical migration、refactoring、監査、性能実験、リリース準備の過程で作成した履歴資料を保存します。ここにある文書は当時の判断・測定・作業記録であり、現在の実装仕様を直接定義しません。

現在の仕様は、リポジトリ直下のREADMEとCONTRIBUTING、[`docs/architecture.md`](../architecture.md)、[`docs/dice-rules.md`](../dice-rules.md)、[`docs/result-contract.md`](../result-contract.md)、[`docs/reference/`](../reference/)を参照してください。履歴資料中の旧パス、旧コマンド、旧上限、phase番号は、その文書が書かれた時点の記録として扱います。

履歴資料を参照して検証を再現する場合は、文書に記載されたcommitや測定環境を確認し、現在のproduction gateと混同しないでください。新しい仕様や判断を追加するときは、履歴資料を更新するのではなく、現行文書またはADRへ記録します。
